# The Vacation Exchange - Key Swap site
Static site, no build step. Upload the whole folder to Netlify, Vercel, cPanel or any host.

Before launch:
1. Replace YOUR_FORM_ID in contact.html and join.html with a Formspree form ID (or your own form endpoint).
2. Replace the text in privacy.html and terms.html with lawyer-approved policies.
3. Swap in the client's own photos if they have them.
